# Python 100 Days

My journey learning Python: daily exercises from the **100 Days of Code: Python** course, plus practice problems from a Python crash course.

This repo is a learning log. The code is written to practice and understand concepts, not to be production-ready.

## Repository Structure

```
python-100-days/
├── Day 1/                      # 100 Days of Code, Day 1
│   ├── Brand Name Generator.py
│   └── Test python.py
└── KY Crash Course Python/     # Practice problems from a Python crash course
    ├── Practice problems for class 1.py
    ├── Practice problems for class 2.py
    ├── Practice problems for class 3.py
    └── Practice probelmms for class 4.py
```

## What's Inside

### Day 1: Working with Strings, Variables and Input
- **Brand Name Generator**: a small program that asks for a city and a product or service, then combines them into a brand name.
- **Test python.py**: notes and practice for `print()`, string concatenation, newlines, `input()`, variables and `len()`.

### KY Crash Course Python
| Class | Topics |
|-------|--------|
| 1 | Data types: `bool`, `int`, `float`, `None`, and the types of mixed expressions |
| 2 | Lists, tuples, indexing, slicing, mutability, and sequence operators |
| 3 | Conditionals (`if` / `elif` / `else`), tracing variable values, and reading code |
| 4 | Loops and tracing how values change as a loop runs |

## Running the Code

You'll need [Python 3](https://www.python.org/downloads/) installed. From the repo root:

```bash
python "Day 1/Brand Name Generator.py"
```

Many of the practice files have their code commented out so I could work through one problem at a time. Uncomment a section to run it.
